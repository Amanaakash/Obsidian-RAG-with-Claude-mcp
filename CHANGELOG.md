## [0.2.0] - 2026-08-12

### Added

- Recursive Obsidian Markdown scanning with hidden and internal-directory exclusions.
- YAML, heading hierarchy, tag, and wiki-link parsing.
- Heading-aware paragraph chunking with stable chunk identifiers.
- Local Ollama embeddings and persistent ChromaDB retrieval.
- Incremental indexing for new, changed, and deleted notes.
- Command-line indexing and dense semantic search with source citations.
- Read-only MCP tools for search, note reading, and vault status.
- Non-blocking startup refresh, cross-process locking, and sanitized status reporting.
- Automated parser, indexing, embedding, path-safety, and MCP stdio tests.
